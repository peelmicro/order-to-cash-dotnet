Restore from a backup copy you took — **never `git checkout --`** — then `touch` the restored file (or `dotnet build --no-incremental`) before the confirming green run, and confirm the restore by re-reading the changed line. An arming table produced without a forced rebuild proves nothing (`CLAUDE.md`, arming protocol).
